# SOP: Screen Coating & Mesh Selection

**Department:** Darkroom  
**Applies To:** Darkroom Technician, Screen Print Manager  
**Tags:** `#darkroom` `#sop` `#mesh` `#emulsion`

---

## 1. Mesh Selection Matrix

Selecting the proper mesh count determines ink deposit, detail resolution, and hand feel on the garment.

| Mesh Count | Best For | Typical Ink Type | Squeegee Durometer |
| :--- | :--- | :--- | :--- |
| **86 – 110** | Heavy underbases on fleece, metallic inks, glitter | Heavy Plastisol | 65 / 70 Single |
| **156 – 160** | Standard spot color on cotton/poly tees, general text | Plastisol / Waterbase | 70 / 90 / 70 Triple |
| **200 – 230** | Halftones (up to 45 LPI), detailed vector line art | Reduced Plastisol / Waterbase | 70 / 90 / 70 Triple |
| **280 – 305** | Simulated process, CMYK process, ultra-soft hand | High-solid Acrylic / Discharge | 80 Single or Triple |

## 2. Emulsion Coating Protocol (1x1 vs 2x1)

We use **Chroma/Tek Dual-Cure Photopolymer Emulsion**.

### Steps:
1. **Screen Inspection:** Verify tension is between **25–30 N/cm** on Newman roller frames or static frames.
2. **Degreasing:** If the screen was reclaimed, ensure no chemical residue or haze remains.
3. **Scoop Coater Technique:**
   - Use the **round edge** of the scoop coater for heavy deposits (fleece).
   - Use the **sharp edge** for standard and high-detail screens.
4. **Coating Stroke:**
   - **Step 1:** Coat shirt side (substrate side) first with smooth, upward pressure.
   - **Step 2:** Coat squeegee side immediately after.
   - For high-density or fleece (110 mesh), apply a **2x1** coat (2 coats shirt side, 1 squeegee side wet-on-wet).
5. **Drying:**
   - Store in the drying cabinet **shirt side DOWN** so gravity pulls the emulsion toward the print side.
   - Target cabinet conditions: **85°F – 95°F (29°C – 35°C)** with relative humidity **under 40%**.
   - Minimum dry time: **45 minutes** before exposure.

:::caution
Never expose damp screens! Moisture inside the emulsion layer causes pinholes and premature stencil breakdown on long automatic runs.
:::
